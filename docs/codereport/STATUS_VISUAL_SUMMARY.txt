🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

1. VERIFY COMPILATION
   $ cd /Users/slametwidodo/IdeaProjects/stockholm
   $ mvn clean compile
   ✅ SUCCESS

2. RUN TESTS (Embedded Kafka)
   $ mvn test
   ✅ PASSED: EventPublisherIntegrationTest
   ✅ PASSED: PaymentControllerIntegrationTest

3. START INFRASTRUCTURE
   $ docker compose up -d
   ✅ Kafka, PostgreSQL, Redis started

4. START SERVICE
   $ cd services/payment-orchestrator
   $ mvn spring-boot:run
   ✅ Service started on http://localhost:8081

5. CREATE PAYMENT
   $ curl -X POST http://localhost:8081/api/v1/payments \
       -H "Content-Type: application/json" \
       -d '{"orderer":"BANK001","beneficiary":"CUST001","amount":500}'
   ✅ Response: {"paymentId":"PAY-...", "correlationId":"corr-..."}

6. VERIFY EVENT IN KAFKA
   $ docker exec -it kafka_container kafka-console-consumer \
       --bootstrap-server localhost:9092 \
       --topic payment.initiated --from-beginning
   ✅ See your event as JSON!
